# website-source — aufgehobene Langtexte, NICHT in der Inline-Doku

Was hier liegt, ist bewusst **nicht** in der In-IDE-Doku verlinkt (steht nicht in
`../registry.ts`, wird nirgends per `?raw` importiert). Es ist gesichert, damit wir
später darauf zurückgreifen können — vor allem als Quelle für den geplanten
**Web-Export** (D9 / WEBSITE_PLAN).

Grund der Auslagerung: Diese Texte sind ausführliche „Hefte" im Douglas-Adams-Ton.
In einem IDE-Seitenpanel liest die niemand durch; dort gehört ein kurzer, knackiger
Schnellstart hin (siehe `../guides/`). Die lange, liebevolle Fassung lebt hier weiter
und wandert später auf die Website.

## Inhalt

- `crumb-sprache.de.md` — das ursprüngliche CRUMB-Einführungsheft (ehem. erste
  Doku-Seite „CRUMB, deine erste eigene Sprache"). Deckt die halbe Sprache in Prosa
  ab: Variablen, `Const`, `Global`, `Dim`, `Type`, `If`, Schleifen, `VWait`. Die
  Keyword-Details liefert in der IDE ohnehin die aus dem SSOT generierte Referenz —
  hier bleibt der erzählerische Langtext für die Website.
